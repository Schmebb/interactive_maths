    The one idea behind every part

    Write the exponent as \(w = u + iv\). Then

    \[e^{w} = e^{u}\,e^{iv},\]

    which is a complex number with modulus \(e^{u}\) and argument \(v\). So to solve \(e^{w} = re^{i\theta}\), match the two pieces:

    • Modulus: \(e^{u} = r\), so \(u = \ln r\). One answer, because the real exponential is one-to-one.
    • Argument: \(v = \theta + 2\pi k\). Infinitely many answers, because adding a full turn lands on the same point.
    \[e^{w} = re^{i\theta} \iff w = \ln r + i(\theta + 2\pi k),\quad k\in\mathbb{Z}.\]

    Every part follows the same recipe: write the right-hand side in polar form, solve for the whole exponent \(w\), then solve for \(z\). The interesting behaviour happens in the last step.

    Why the solutions are points

    An equation like \(e^{2iz} = -2\) asks the output to land on one exact spot. That means getting two things right at once:

    • The distance from the origin (the modulus). In (a) this depends only on the height \(y\), so it fixes \(y = -\tfrac{\ln 2}{2}\).
    • The direction (the angle). In (a) this depends only on \(x\), so it fixes \(x = \tfrac{\pi}{2}\).

    Two conditions pin down both coordinates, which gives a single point. It's the same reason that "\(x = 1\) and \(y = 2\)" describes a point, while "\(x = 1\)" alone describes a line.

    There are infinitely many points because the angle wraps around. Once the direction is right, moving \(x\) further by \(\pi\) spins the output one full turn back to the same spot. In the explorer, drag \(z\) sideways along the row in (a) and watch the output circle the origin.

    The odd ones out follow from the same logic. Part (e) only asks for the distance to be 2, so only \(x\) is fixed and you get a whole line. Part (f) can only output positive real numbers, so it never reaches \(i\).

    Parts a to g

    (a) \(e^{2iz} = -2\)

    1. \(-2\) has modulus 2 and points left, so its argument is \(\pi\): \(-2 = 2e^{i\pi}\).
    2. Match the exponent: \(2iz = \ln 2 + i(\pi + 2\pi k)\).
    3. Divide by \(2i\). Since \(\tfrac1i = -i\), a real part \(a\) becomes \(-ia\) and an imaginary part \(ib\) becomes \(b\).
    \[z = \frac{\pi}{2} + \pi k - \frac{i\ln 2}{2}\]

    Before dividing, the solutions for \(w\) form a vertical column. Dividing by \(i\) rotates the plane by \(90^\circ\), turning the column into a row, and dividing by 2 halves the spacing. The result is a horizontal row at \(y \approx -0.35\), spaced \(\pi\) apart.

    (b) \(e^{z} = 1\)

    1. \(1\) has modulus 1 and argument 0.
    2. The exponent is \(z\) itself, so \(z = \ln 1 + i(0 + 2\pi k)\).
    \[z = 2\pi i k\]

    Since \(\ln 1 = 0\), every solution is on the imaginary axis: \(0, \pm 2\pi i, \pm 4\pi i, \dots\) This is the periodicity fact in its purest form: \(e^z = 1\) exactly when \(z\) is a multiple of \(2\pi i\).

    (c) \(e^{3z} = 1 + i\)

    1. \(1+i\) has modulus \(\sqrt2\) and sits at \(45^\circ\): \(1+i = \sqrt2\,e^{i\pi/4}\).
    2. Match the exponent: \(3z = \tfrac12\ln 2 + i\left(\tfrac{\pi}{4} + 2\pi k\right)\).
    3. Divide by 3. A real number only scales, it doesn't rotate.
    \[z = \frac{\ln 2}{6} + i\left(\frac{\pi}{12} + \frac{2\pi k}{3}\right)\]

    A vertical column like (b), shifted right to \(x \approx 0.12\), with spacing \(\tfrac{2\pi}{3}\) instead of \(2\pi\).

    (d) \(e^{iz} = 1 - i\)

    1. \(1-i\) has modulus \(\sqrt2\) and sits at \(-45^\circ\): \(1-i = \sqrt2\,e^{-i\pi/4}\).
    2. Match the exponent: \(iz = \tfrac{\ln 2}{2} + i\left(-\tfrac{\pi}{4} + 2\pi k\right)\).
    3. Multiply by \(-i\), which is the same as dividing by \(i\).
    \[z = -\frac{\pi}{4} + 2\pi k - \frac{i\ln 2}{2}\]

    As in (a), the factor of \(i\) rotates the column into a row, at the same height \(y = -\tfrac{\ln 2}{2}\). There's no extra number multiplying \(i\), so the spacing stays \(2\pi\).

    (e) \(|e^{z}| = 2\)

    This time you're only told the modulus. With \(z = x+iy\),

    \[|e^{z}| = |e^{x}|\,|e^{iy}| = e^{x}\cdot 1 = e^{x},\]

    because \(e^{iy}\) is always on the unit circle. So \(e^{x} = 2\), giving \(x = \ln 2\), with no condition on \(y\).

    \[\operatorname{Re} z = \ln 2\]

    The whole vertical line at \(x \approx 0.69\). Knowing only the modulus fixes the real part and leaves the angle free. In the explorer, drag along the line and the output slides around the circle of radius 2.

    (f) \(e^{|z|} = i\)

    The exponent \(|z|\) is always a real number that is 0 or greater, and the exponential of a real number is always a positive real number. But \(i\) has argument \(\tfrac{\pi}{2}\), while \(e^{|z|}\) always has argument 0.

    No solutions. The diagram is empty.

    The trap is to take logs blindly and write \(|z| = i\left(\tfrac{\pi}{2} + 2\pi k\right)\). The left side is real and the right side is purely imaginary and never 0, so that can't work.

    (g) \(\overline{e^{iz}} = e^{i\bar z}\)

    1. Conjugation passes through the exponential: \(\overline{e^{w}} = e^{\bar w}\), because conjugating \(e^{u}(\cos v + i\sin v)\) flips the sign of \(\sin v\).
    2. With \(w = iz\): \(\overline{iz} = \bar i\,\bar z = -i\bar z\). So the equation is \(e^{-i\bar z} = e^{i\bar z}\).
    3. Multiply both sides by \(e^{i\bar z}\): \(e^{2i\bar z} = 1\).
    4. By (b), \(2i\bar z = 2\pi i k\), so \(\bar z = \pi k\). That's real, so \(z = \pi k\).
    \[z = \pi k\]

    Points on the real axis at \(0, \pm\pi, \pm 2\pi, \dots\) Check \(z = \pi\): the left side is \(\overline{e^{i\pi}} = -1\) and the right side is \(e^{i\pi} = -1\).

    Why (a) has \(\pi k\) and not \(2\pi k\)

    Here is part (a) again, one operation per step.

    1. Polar form of \(-2\). Modulus 2, angle \(\pi\). You can go round any number of extra full turns and land on the same point, so the angle is \(\pi + 2\pi k\): \[-2 = 2e^{i(\pi + 2\pi k)}.\] This is where the \(2\pi k\) enters. It describes the angle of \(-2\).
    2. Write 2 as an exponential. \(2 = e^{\ln 2}\), so \(-2 = e^{\ln 2 + i(\pi + 2\pi k)}\).
    3. Match exponents. \[2iz = \ln 2 + i\pi + 2\pi i k.\] The \(2\pi k\) is attached to \(2iz\), not to \(z\).
    4. Divide by 2. \[iz = \frac{\ln 2}{2} + \frac{i\pi}{2} + \pi i k.\] This is where \(2\pi k\) becomes \(\pi k\).
    5. Divide by \(i\) (multiply by \(-i\)), term by term: \[\tfrac{\ln 2}{2}\cdot(-i) = -\tfrac{i\ln 2}{2},\qquad \tfrac{i\pi}{2}\cdot(-i) = \tfrac{\pi}{2},\qquad \pi i k\cdot(-i) = \pi k.\] So \(z = \tfrac{\pi}{2} + \pi k - \tfrac{i\ln 2}{2}\).

    Check with actual numbers

    Take \(z_0 = \tfrac{\pi}{2} - \tfrac{i\ln 2}{2}\). Then \(2iz_0 = \ln 2 + i\pi\), so \(e^{2iz_0} = 2e^{i\pi} = -2\). Now move one step of \(\pi\): \(z_1 = z_0 + \pi\) gives \(2iz_1 = 2iz_0 + 2\pi i\), and \(e^{2\pi i} = 1\), so \(e^{2iz_1} = -2\) too. If you wrote \(2\pi k\), you'd miss \(z_1\).

    The same thing in trig

    Solving \(\cos(2x) = 1\) gives \(2x = 2\pi k\), so \(x = \pi k\). The exponent turns twice as fast as \(z\), so \(z\) only needs half the distance to complete a full cycle. In general, if the exponent is \(az\), the spacing is \(\tfrac{2\pi}{|a|}\).
