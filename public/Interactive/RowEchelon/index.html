Row Echelon Workbench

Turn a linear system into its augmented matrix, then row-reduce it yourself with operations like R2 -> R2 - 2R1. Arithmetic stays exact, in fractions.

Step 1

Your system

Row operation syntax

Swap: R1 <-> R2

Scale: R1 -> (1/3)R1

Replace: R2 -> R2 - 2/3R1

Combine: R3 -> 3R3 - 5R1

→, = and ↔ work too. R1 -> R2 is read as a swap.
